Data cut release guide

Purpose:
- This folder is a frozen, shareable cut of the exact data used for the paper.

Subfolders:
- source_subset/: raw sampled posts/comments and subset metadata.
- annotations/: released label files used in analysis.
- analysis_inputs/: post-level analysis tables/datasets.
- post_results/: frozen post-level result tables referenced in appendices.
- manual_verification/: manual-audit inputs and alignment-evaluation outputs.
- dyadic/: H3 dyad-level persistence outcomes and hypothesis-test artifacts.
- topic_controls/: NLP topic-control robustness artifacts (topic IDs, FE models, diagnostics).
- JSON/: JSON mirror for easy manual inspection.

Notes:
- Parquet files are the canonical machine-readable release format.
- JSON files are inspection-friendly copies.
- Manual verification uses:
  - manual_audit_200_examples.xlsx (expert-reviewed labels)
  - manual_audit_200_examples_original.xlsx (original model labels before manual edits)
  - alignment outputs generated by agent_psr/scripts/run_manual_alignment_audit.py
