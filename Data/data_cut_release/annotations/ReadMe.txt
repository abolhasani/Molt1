Annotations guide

Files and methods:
- post_labels_keyword.parquet:
  post-level labels from annotate_posts_keyword.py (rule-based keyword baseline).
- post_labels_fewshot.parquet:
  post-level labels from annotate_posts_llm.py --method fewshot.
- post_labels_cabsallm.parquet:
  post-level labels from annotate_posts_llm.py --method cabsallm (grouped-context; legacy key name).
- labeled_subset_comments.parquet:
  comment-level labels from run_psr_analysis.py using regex/rule-based indicator logic
  in build_indicators() (AttachmentIntimacy, ReplySeekingReciprocity,
  SelfIdentificationToOP, AnyPSRIndicator).

Clarification:
- labeled_subset_comments is not generated by the few-shot or grouped-context LLM annotators.
