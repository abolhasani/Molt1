Results folder guide

What is here:
- Comment-level PSI/PSR analysis outputs (from run_psr_analysis.py):
  indicator_prevalence.csv, association_tests.csv, depth_tests.csv,
  permutation_tests.csv, analysis_summary.json, labeled_subset_comments.parquet, etc.
- Post-level annotation and core test outputs:
  post_labels_*.parquet, post_method_prevalence.csv, post_hypothesis_*.csv/json,
  post_nullification_tests.csv, post_temporal_fe_robustness.csv,
  post_affordance_activation_tests.csv, post_interaction_checks.csv,
  post_presence_threshold_tests.csv, post_psr_count_dose_response.csv.
- Additional robustness outputs:
  post_clustered_author_robustness.csv, post_hypothesis_logit_controls_fdr.csv,
  post_additional_placebo_technical.csv, post_additional_placebo_technical_summary.csv.
- Dyadic persistence outputs for H3 (from run_dyadic_hypothesis_tests.py):
  post_dyad_pair_events.parquet/csv, post_dyad_outcomes.parquet/csv,
  post_dyad_hypothesis_tests.csv, pair_dyad_hypothesis_tests.csv,
  post_dyad_hypothesis_summary.json.
- NLP topic-control robustness outputs (from run_topic_controlled_models.py):
  post_topic_k_selection.csv, post_topic_top_terms.csv, post_topic_profile.csv,
  post_topic_controlled_logit_results.csv, post_topic_confound_lr_tests.csv,
  post_topic_assignments.parquet/csv, post_topic_controlled_summary.json.
- Manual adjudication package is tracked in:
  - manual_verification/
  - agent_psr/data_cut_release/manual_verification/

Important label provenance:
- labeled_subset_comments.parquet is NOT from few-shot/grouped-context LLM annotation.
- It is generated by run_psr_analysis.py using rule-based regex indicators
  in build_indicators() (keyword/pattern logic with target gating).

How to regenerate:
- python agent_psr/scripts/run_psr_analysis.py
- python agent_psr/scripts/build_post_thread_dataset.py
- python agent_psr/scripts/annotate_posts_keyword.py
- python agent_psr/scripts/annotate_posts_llm.py --method fewshot
- python agent_psr/scripts/annotate_posts_llm.py --method cabsallm
- python agent_psr/scripts/run_post_hypothesis_tests.py
- python agent_psr/scripts/run_dyadic_hypothesis_tests.py
- python agent_psr/scripts/run_additional_reviewer_checks.py
- python agent_psr/scripts/run_topic_controlled_models.py
- python agent_psr/scripts/export_manual_audit_sample.py
- python agent_psr/scripts/run_manual_alignment_audit.py
